# Four in a Row

## ▶ [Play the game](https://libyan11.github.io/four-in-a-row/)

https://libyan11.github.io/four-in-a-row/

Four in a Row in your browser, on phone or computer. Play online with a friend, or against the computer on Easy, Medium or Hard. Part of [Game Night](https://libyan11.github.io/).

**Play with a friend:** one person taps *Create a room* and shares the 4-letter code or link. The other types the code and taps *Join room*.

**Rules**
- Tap a column to drop a disc to the lowest empty space.
- First to get four in a line wins: across, up and down, or diagonal.
- A full board with no four in a row is a draw.
- Whoever went second goes first in the next game.
